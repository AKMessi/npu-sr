# Example assets

`input.png` (256×160) and `reference.png` (512×320) are generated by
`python scripts/create_example.py` with Pillow and NumPy, using Pillow's default font.
The card is original artwork included under the repository's MIT license.

`bicubic_2x.png` and `npu_sr_2x.png` are actual outputs of:

```powershell
npu-sr upscale examples/input.png -o outputs/npu.png --device npu --comparison-dir outputs/compare
```

Generated comparison files were copied here for README display after local QNN
verification. The image is an intentionally simple test pattern; also try a real
photo of your own to judge texture recovery and artifacts.
